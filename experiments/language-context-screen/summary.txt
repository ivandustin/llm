Tiny Shakespeare context-length screen

Three seeds per model at contexts 32 and 128. Each run used 3,000 Adam updates at batch size 64.
Rates 0.0003 and 0.001 were screened on validation at 1,000 updates using separate seed 3.
Training and evaluation targets match across models and lengths. The validation and test splits
each contain 4,096 sampled windows, drawn from the usual contiguous 80/10/10 split.
Concat + GELU keeps the width-128 architecture and 100k parameter ceiling (hidden widths 271 and 233).
Token-product keeps width 64 and hidden width 576. The Transformer is the current width-64 reference.

Means ± sample SD across seeds. Training seconds exclude compilation and evaluation.
Inference is warmed, JIT-compiled batch-one latency with resident inputs on an Intel Core Ultra 7 155H.
