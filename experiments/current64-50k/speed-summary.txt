Current token-product pooling vs sinusoidal Transformer: CPU speed benchmark
2026-11-24; seed-0 50,000-update checkpoints; FP32; Intel Core Ultra 7 155H.
JAX 0.10.1 CPU backend; affinity CPUs 0-21; OMP_NUM_THREADS=1; OPENBLAS_NUM_THREADS=1.
Seven alternating warmed trials. Median milliseconds/request or update; speedup = Transformer / pooling.
Inference: 500 requests/trial, 20 warmups, synchronized each request.
Training: batch64, Adam .001, 200 updates/trial; Python loop synchronizes complete final state;
compiled scan carries continuous model/Adam state across 200 updates. Fresh Adam state per trial.
Compilation, input generation, and host transfers excluded; resident inputs; no KV cache.
Each compiled trainer passed five-update loss and full model/Adam state parity (rtol1e-4, atol1e-5).
No concurrent benchmark jobs. Timing updates discarded; checkpoint files unchanged.
