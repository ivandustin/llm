# Last-Token-Conditioned Pooling for Associative Recall and Language Prediction

This project explores a small sequence model that combines learned position and
token embeddings into a pooled representation conditioned on the final token.
It compares the model with a causal Transformer on synthetic retrieval tasks and
next-character prediction on Tiny Shakespeare.

See the [paper (PDF)](paper/paper.pdf) for the models, experiments, and results.
